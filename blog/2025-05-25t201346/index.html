Using Rustdesk with Tailscale

May 25, 2025
3 min read

I have a Steam Deck and a Lenovo Ideapad running SteamOS and Debian. I mostly use Debian for devlopement. So I’d like to remote desktop into my Laptop from the steam deck. I’ll be using RustDesk and Tailscale. This post will focus on configuring RustDesk and setting up the relay server on the laptop.

Requirements

  • Tailscale should be configured on both machines.
  • Docker should be installed for the relay server

Setting up client Machines

Make sure to get the version depending on your distro from the releases page.

SteamOS is a flavour of Arch KDE. So I just downloaded RustDesk from the KDE store.

For my laptop running Debian 12 bookworm I installed the .deb package file and am using RustDesk v1.4.0 on both machines.

wget https://github.com/rustdesk/rustdesk/releases/download/1.4.0/rustdesk-1.4.0-aarch64.deb
sudo apt install ./rustdesk-1.4.0-x86_64.deb

Configuring the relay server

In this setup one machine wil be running the Rustdesk client and server simultaneously. This will be my Lenovo Ideapad.

Create a directory and docker-compose.yml file and paste the example from the rustdesk page into the compose file and run the container

mkdir rustdesk
cd ./rustdesk 
touch docker-compose.yml
docker compose up -d

You should see two containers running

shivkar2n@lenovo-s540-ideapad Desktop docker ps -a

A public key will be created in the container directory.

shivkar2n@lenovo-s540-ideapad rustdesk tree
.
├── data
│   ├── db_v2.sqlite3
│   ├── db_v2.sqlite3-shm
│   ├── db_v2.sqlite3-wal
│   ├── id_ed25519
│   └── id_ed25519.pub
└── docker-compose.yml

The client by default uses port 21118. Go to Settings > Security configure it to use a different port since the server will be using port range 21114-21119. Make sure that direct IP access is enabled and configure a permanant password.

Then open ports 21114-21120 using the firewall. In my case that’s ufw.

sudo ufw allow <PORT_NO>

Now get the Tailscale IP of the relay server, for me this is my Lenovo Ideapad.

(deck@steamdeck ~)$ sudo tailscale status
100.64.234.117  steamdeck            shivkar2n@   linux   -
100.127.50.92   lenovo-s540-ideapad  shivkar2n@   linux   active; direct 192.168.29.50:41641, tx 35948000 rx 119564256
100.119.246.82  raspberrypi          shivkar2n@   linux   offline
100.64.203.12   xiaomi-m2101k6i      shivkar2n@   android offline

Go to Settings > Network > ID/Relay Server. I’ll be using the above IP of my Lenovo S540 Ideapad as the ID and relay server. Paste the contents of the id_ed25519.pub as the key and repeat the same steps on the Steam Deck.

After that I just connect to the Lenovo using its Desktop ID and remote login from my Steam Deck.
